## Ko‘p satrli kod

Uchta teskari apostrof bilan kod blokini oching va yoping. Birinchi qatorda til nomini yozsangiz, sintaksis rang bilan ajratiladi.

::code-preview
---
class: "[&>div]:*:my-0 [&>div]:*:w-full"
---
```js
const title = 'Turkion'
console.log(title)
```

````mdc

````

## Qatorni ajratib ko‘rsatish

