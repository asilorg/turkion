Turkion maqolasiga rasm qo‘shishdan oldin fayl manbasini, muallifini va foydalanish shartlarini tekshiring. Muqobil matn (`alt`) tasvirda nima ko‘rsatilganini qisqa tushuntirishi kerak.

## Markdown yordamida rasm

Rasmning saytdagi manzilini `()` ichiga, tasvir tavsifini `[]` ichiga yozing. Quyidagi mahalliy fayl misol sifatida ishlatiladi.

::code-preview
![Samarqand masjidi tasviri](/miniatures-web/timurid/Building_Samarkand_Mosque.jpg.webp)

#code
```mdc
![Samarqand masjidi tasviri](/miniatures-web/timurid/Building_Samarkand_Mosque.jpg.webp)
```
::

::note
Rasm ostidagi izohda tasvirning mavzusi va zarur bo‘lsa sanasi ko‘rsatiladi. Mualliflik hamda litsenziya haqidagi tasdiqlangan ma’lumotni alohida manba bilan bog‘lang; noma’lum ma’lumotni taxmin qilmang.
::

## O‘lchamni belgilash

Ko‘rsatish o‘lchami yoki boshqa atribut kerak bo‘lsa, `:img` komponentidan foydalaning. `src` fayl manzili, `alt` muqobil matn, `height` esa ko‘rsatiladigan balandlikdir.

::code-preview
:img{src="/miniatures-web/timurid/Building_Samarkand_Mosque.jpg.webp" alt="Samarqand masjidi tasviri" height="150"}

#code
```mdc
:img{src="/miniatures-web/timurid/Building_Samarkand_Mosque.jpg.webp" alt="Samarqand masjidi tasviri" height="150"}
```
::

## Tashqi sahifani joylashtirish

`:iframe` tashqi sahifa yoki videoni maqola ichida ko‘rsatishi mumkin. Manzil, sarlavha va joylashtirishga ruxsatni oldindan tekshiring. Muhim ma’lumot faqat tashqi oynada qolmasin: matnda ham qisqacha bayon qiling va oddiy havola bering.

```mdc
:iframe{src="https://example.org/embed/example" title="Tashqi material" style="aspect-ratio: 16/9;"}
```

Bu sintaksis namunasidagi `example.org` haqiqiy media manbasi emas. Joylashtirishdan oldin uni foydalanishga ruxsat berilgan haqiqiy manzilga almashtiring.
